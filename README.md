## Setup

Python 3.11 or newer and Git are required. From the cloned repository:

```bash
python -m venv .venv
```

Activate the environment on Windows:

```powershell
.venv\Scripts\Activate.ps1
```

On macOS or Linux:

```bash
source .venv/bin/activate
```

Then install the repository requirements:

```bash
python -m pip install -r requirements.txt
```

Each weekly folder contains its own README and requirements file. Weeks 1 and
3 are complete; later weeks are added in separate commits.
